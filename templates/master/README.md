# Master lesson template

This is the first executable visual master for PM1.

It intentionally contains neutral instructional copy. Real lessons replace all placeholders with verified lesson content.

## Design basis
- official Hexlet palette and Manrope typography;
- semantic teaching patterns extracted from the uploaded P001 presentation;
- evidence/causal-chain teaching method extracted from the uploaded P001 teacher guide;
- Kazakhstan college logo is required, but is not approximated or recreated. The exact verified SVG from hexly.kz must be imported before production branding is declared complete.

## Usage
Use the slide types as a library. A lesson is not required to use every layout or keep the same order.
