# HEXLET COLLEGE — Web Design Education System

Version: 1.0 draft

## Sources of truth
1. Kazakhstan college identity/logo: official hexly.kz website. Do not substitute the generic Hexlet wordmark.
2. Core Hexlet visual system: Hexlet/brand-assets.
3. Presentation interaction patterns: Hexlet/slidev-theme-hexlet and Hexlet/presentations.

## Typography
Primary family: Manrope.
- Headings: Manrope SemiBold (600)
- Body: Manrope Regular (400)
- Code/technical snippets: monospace; use only when required by content.

## Core palette
- Ink: #151618
- Paper: #EEEEEC
- Primary violet: #433EFF
- Graphite: #414141
- Muted: #C7C7C7
- Accent violet: #D16FFF
- Accent cyan: #00C2FF

## Presentation principles
- 16:9.
- High contrast.
- One teaching purpose per slide.
- Visual hierarchy before decoration.
- Large readable typography for classroom projection.
- Images must explain the slide, not fill empty space.
- Avoid repeating the same composition or illustration.
- Interactive slides are semantic types, not decorative variants.
- The first slide is a stable course identity surface.
- A consistent footer/result zone may be used across lesson slides.
- No Moodle references inside teaching slides.

## Required semantic slide types
Cover, theory, definition, visual example, compare, demonstration, question, discussion, guided practice, independent practice, checklist, control, summary.

## Logo rule
The Kazakhstan college logo from hexly.kz is the required mark for this course. Preserve its original SVG geometry. Never recreate the wordmark with an approximate font. Never stretch, skew, outline, recolor outside approved contrast variants, or alter spacing inside the mark.
