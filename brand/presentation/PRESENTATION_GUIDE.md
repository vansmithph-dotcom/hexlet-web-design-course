# Presentation guide

## Canvas
16:9 widescreen.

## Reading hierarchy
1. Lesson/section context.
2. Main statement or question.
3. Supporting explanation.
4. Visual evidence/example.
5. Action or conclusion.

## Slide families
- Cover: stable identity + lesson number + topic + hero visual.
- Theory: concept + concise explanation + visual.
- Definition: term + plain-language definition + example.
- Compare: A/B with one controlled variable.
- Demonstration: teacher action in observable steps.
- Question: one clear prompt for discussion.
- Guided practice: students act with teacher.
- Independent practice: deliverable + constraints + time + success criteria.
- Checklist: observable verification points.
- Control: question/task that checks taught content.
- Summary: what the student can now identify/do.

## Visual system
Dark surfaces are the default classroom mode. Use official Hexlet violet/cyan accents selectively. Prefer large imagery, diagrams, interface crops, before/after comparisons, and controlled examples over decorative stock imagery.

## Accessibility
Maintain strong contrast, avoid text over busy images, do not encode meaning by color alone, and keep critical classroom text readable from the back of the room.
