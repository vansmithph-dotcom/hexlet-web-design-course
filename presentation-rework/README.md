# Presentation Rework

Рабочая зона для переработанных презентаций курса.

## Правила
- Исходные презентации в основных каталогах не заменяются.
- Каждое занятие хранится отдельно: `P001/`, `P002/`, …
- Новая презентация получает суффикс `_NEW.pptx` до утверждения.
- `assets/` содержит изображения, SVG и другие ресурсы конкретного занятия.
- `CHANGELOG.md` фиксирует все изменения относительно исходной версии.
- После утверждения перенос в основную структуру выполняется отдельным решением.

## Структура
```text
presentation-rework/
├── README.md
└── P001/
    ├── README.md
    ├── CHANGELOG.md
    └── assets/
        └── README.md
```
