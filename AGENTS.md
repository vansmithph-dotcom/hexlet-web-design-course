# Course automation rules

1. Preserve the fixed visual identity of the course.
2. Never invent lesson content when an authoritative current source exists.
3. Read the current lesson source before migration.
4. A lesson must contain theory, teacher demonstration, guided interaction, independent practice, and control.
5. Do not mention Moodle inside teaching slides; Moodle is the delivery shell.
6. Do not commit credentials, student personal data, grades, attempts, or submissions.
7. Validate before publishing.
8. Publish to staging before production.
9. Do not delete legacy PPTX/DOCX during migration.
10. P026 is the first pilot.
