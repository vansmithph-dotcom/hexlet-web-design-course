Status: DISABLED pending audit.

Before enabling synchronization, verify:
1. Moodle version.
2. Course administrator permissions.
3. Course format.
4. External URL and iframe policy.
5. H5P availability.
6. Web Services status.
7. Token creation rights.
8. Allowed REST functions.

GitHub may publish learning content to Moodle. Moodle remains authoritative for users, groups, submissions, attempts, grades, and progress.
