# П001 — памятка студенту

Перед началом работы осмотри рабочую зону.

Формула ответа на занятии:
**вижу → риск → действие**.

Проверь проход, положение кабелей, видимое состояние питания, жидкости рядом с оборудованием и возможность начать работу без препятствий вокруг рабочего места.

Не заменяй наблюдение словами «нормально», «плохо», «опасно». Назови конкретный признак.
