# П001 — устная практика

## Задание
Сравни две ситуации рабочего места.

За 90 секунд найди наблюдаемые признаки. Затем выбери один признак и сформулируй ответ:

1. Что видно?
2. Где это находится?
3. С каким риском связано?
4. Что нужно изменить до начала работы?
5. Что по одному изображению доказать нельзя?

Файл сдавать не требуется. Результат занятия подтверждается коротким профессиональным устным объяснением.
